① 進階課程地圖

每堂課包含核心原理、材料接線、操作步驟、即時模擬、Arduino 程式碼及隨堂測驗。

② 上課前準備

主要使用 Arduino UNO R3，最後一課改用具有內建 Wi-Fi 的 ESP32 DevKit。

💻

軟體

Chrome／Firefox／Edge、Arduino IDE 2.x、必要函式庫與 USB 資料線。網頁實驗是獨立模擬，不會自動上傳程式。

🛠️

進階電子元件

OLED、MPU6050、LM35、microSD、PIR、HC-05、28BYJ-48、ULN2003、MOSFET 與直流風扇。

📡

網路與整合

ESP32 DevKit、光敏電阻、電阻與 2.4 GHz Wi-Fi。請勿將真實密碼與 API 金鑰公開到 GitHub。

⚠️ 用電安全與適用範圍：實作只使用規格相容的低壓元件。不同模組供電電壓與腳位可能不同，接線前以手上的模組資料為準。本網站是教學模擬，不會直接控制開發板；外接馬達必須有驅動器、合適的獨立供電與共地。
