BEFORE YOU START

🎒 課前準備

每個人或每組準備一台電腦、一組 Arduino UNO R3 教具即可開始。

💻

軟體與電腦

Chrome／Edge、Arduino IDE 2.x、USB 資料線。網頁模擬不需要安裝 IDE。

Arduino IDE 官方下載 ↗
🔌

電路基礎材料

Arduino UNO R3、麵包板、杜邦線、LED、220–330Ω 電阻、按鈕、可變電阻。

各堂課另有材料表
📡

感測與控制模組

光敏電阻、10kΩ 電阻、被動蜂鳴器、DHT11、HC-SR04、SG90 伺服馬達。

第 6–10 堂會逐步使用
⚠️
操作安全

接線前先拔除電源；LED 一定要串限流電阻；SG90 建議使用穩定外部 5V 供電並與 UNO 共 GND。此網頁為軟體模擬，不會直接控制實體開發板。
